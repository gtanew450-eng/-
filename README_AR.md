# حاسبة الأذون المتطور — مشروع Android

## ما يتضمنه هذا الإصدار
- تطبيق Android أصلي باستخدام Kotlin وJetpack Compose، بواجهة عربية RTL وتصميم مناسب للهاتف.
- حاسبة شراء وفق معادلات ورقة «شراء» في ملف Excel المرفق.
- حاسبة استرداد وفق معادلات ورقة «إسترداد»، مع احتساب الأيام المتبقية والربح/الخسارة والضريبة.
- مقارنة مستقلة لآجال 91 و182 و273 و364 يومًا باستخدام العائد الذي يدخله المستخدم.
- سجل محلي محفوظ على الهاتف لآخر 100 عملية، مع إمكانية مسحه.
- يظل الحساب متاحًا دون اتصال بالإنترنت.

## معادلات Excel المنقولة
### الشراء
- معامل القيمة الحالية = `1 / (1 + (المدة / 365 × العائد / 100))`
- المبلغ المخصوم = معامل القيمة الحالية × القيمة الاسمية
- العائد = القيمة الاسمية − المبلغ المخصوم
- الضريبة = العائد × 20%
- صافي العائد = العائد − الضريبة
- المبلغ آخر المدة = القيمة الاسمية − الضريبة

### الاسترداد
- معامل الشراء = `1 / (1 + (مدة الإذن / 365 × عائد الشراء / 100))`
- تكلفة الشراء = معامل الشراء × القيمة الاسمية
- الأيام المتبقية = مدة الإذن − الأيام المنقضية
- معامل الاسترداد = `1 / (1 + (عائد الاسترداد / 100 × الأيام المتبقية / 365))`
- قيمة الاسترداد = القيمة الاسمية × معامل الاسترداد
- ربح/خسارة الاسترداد = قيمة الاسترداد − تكلفة الشراء
- ضريبة الاسترداد = صفر عند الخسارة، وإلا 20% من الربح
- صافي ربح/خسارة الاسترداد = الربح/الخسارة − الضريبة
- المبلغ النهائي = القيمة الاسمية − (عائد الشراء قبل الضريبة − ربح/خسارة الاسترداد)

## حدود هذا الإصدار — مهم
- **لم يتم بعد ربط التطبيق آليًا بنتائج مزادات البنك المركزي المصري.** مصدر الأسعار المعتمد في التصميم هو الطرح الأولي فقط، لكن إدخال العائد حاليًا يدوي. لم يتم اختراع واجهة API أو اعتبار أي عائد يدوي سعرًا رسميًا.
- المقارنة تستخدم العائد نفسه لجميع الآجال؛ لذلك هي مقارنة حسابية وليست مقارنة مزادات فعلية متزامنة.
- نسبة الضريبة 20% منقولة من ملف Excel، ويجب التأكد من انطباقها على حالة المستخدم ومن البنك قبل اتخاذ قرار مالي.
- يجب مراجعة التطبيق واختبار معادلاته مع البنك/المحاسب قبل الاعتماد الاستثماري.

## بناء APK أونلاين مجانًا
أُضيف ملف GitHub Actions لبناء APK تلقائيًا. اتبع الخطوات التفصيلية في `BUILD_ONLINE_AR.md`. بعد نجاح التشغيل، نزّل Artifact باسم `TreasuryBills-Android-APK` من صفحة Actions.

إعدادات البناء: Android Gradle Plugin 8.7.3، Kotlin 2.0.21، Gradle 8.9، JDK 17، Android SDK 35، والحد الأدنى Android 8.0 (API 26).
